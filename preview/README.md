# Awful Cases · Storybook

HTML-референсы интерфейса Windows/AutoHotkey v2, не нативное приложение.

Истории: Типографика, клавиши, состояния кнопок, настройки, трей, конфликт сочетаний.

Запуск в каталоге preview: `npm ci`, `npm run storybook`. Сборка: `npm run storybook:build`.

Проверено 2026-11-07 на Titan (Node 24): `npm run storybook:build` → OK.

GitBook (не опубликован): https://app.gitbook.com/o/vNK58vV2S63vxervMh3G/sites/site_ENCIu

Ограничение: сборка не подтверждает соответствие нативному UI. Деплой и runtime не меняются.
